# MapCon 🌍

MapCon is a powerful, interactive, and beautifully designed web application for plotting, tracking, and animating your global travel itineraries. Built using **Leaflet** and natively stylized with Vanilla CSS, MapCon allows you to drag-and-drop accommodations, map intricate routes, and visualize your trips across customized geographic shapes.

## Features ✨

- **Interactive Global Mapping**: Search and add any country in the world. MapCon dynamically pulls background GeoJSON data to visually color and trace international borders.
- **Trip Timeline Animation**: Use the responsive timeline slider to animate the chronological progression of your trip—watch as your route and cities appear step-by-step.
- **Drag & Drop Itineraries**: Reorder your stays visually in the sidebar, and watch the map routing lines automatically recalculate and redraw.
- **Deep i18n Localization**: Fully native dual-language support. Toggle seamlessly between English and Traditional Chinese (Hong Kong) (`zh-HK`), instantly translating the entire UI, map labels, and dynamic geographic regions.
- **Custom Color Palettes**: Overwrite default map aesthetics by assigning custom hex colors to specific countries.
- **Save & Export**: Export your entire trip architecture (including custom colors, translations, routes, and selected nations) to a portable JSON file, and load it later to pick up right where you left off.
- **Mobile-First Responsive Design**: Flawlessly adapts to Safari, Chrome, and iOS environments with dynamic viewport (`dvh`) bounds and Apple `safe-area-insets` to ensure a smooth, native app-like feel.

## Built With 🛠️

- **HTML5 & Vanilla JavaScript**: Pure, lightning-fast DOM manipulation without heavyweight frameworks.
- **CSS3 Variables & Flexbox/Grid**: A custom-built, modern glassmorphism design system.
- **Leaflet.js & CartoDB**: Powering the map rendering engine and premium basemap tiles.
- **Sortable.js**: Driving the buttery-smooth drag-and-drop itinerary lists.
- **FontAwesome**: For scalable vector iconography.

## Getting Started 🚀

1. Clone the repository: `git clone https://github.com/LawFuHin/MapCon.git`
2. Open `index.html` in any modern web browser.
3. Start typing in the **Countries visited** section, or use the global dropdown to select any nation on Earth.
4. Click **Add stay** to drop a marker onto the map, and watch your routes come to life!
